<h1 class="mc-hero__title">Materials Commons Tiers</h1>

<p class="mc-hero__tagline">Four levels of participation in the Materials Commons data space, built on DCAT-AP, DCAT-3 and the Dataspace Protocol.</p>

<p class="mc-hero__text"> These are the provider-side profiles for the Materials Commons project: minimal, concrete requirements for publishing datasets and services. Tier 0 is a DCAT-AP catalogue served as a file and is outside DSP. Tier 1 serves the catalogue from an endpoint, with pagination and DCAT-AP on request, and still implements none of contract negotiation or transfer, so it makes no DSP conformance claim. Tier 2 is the first full DSP implementation and Tier 3 adds what DSP leaves optional. Tier 2 and Tier 3 are outlines so far. </p>

<p class="mc-hero__text"> A catalogue or a download may be gated behind a bearer token at any tier, so restricting access costs no level. Start with the tier model if you want the shape of the ladder before the specifications. </p>

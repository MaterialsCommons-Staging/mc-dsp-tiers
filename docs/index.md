<h1 class="mc-hero__title">Materials Commons DSP Tiers</h1>

<p class="mc-hero__tagline">Tiered profiles of the Dataspace Protocol, DCAT-3 and DCAT-AP for open materials data.</p>

<p class="mc-hero__text"> These are the provider-side profiles for the Materials Commons project: minimal, concrete requirements for publishing datasets and services using the Dataspace Protocol (DSP), DCAT-AP and DCAT-3. Tier 1 is public read throughout. Tier 0 is public read as well, except that a distribution may gate its download behind a bearer token. </p>

<p class="mc-hero__text"> Tier 0 is a plain DCAT-AP catalogue served over HTTP GET and is outside DSP. Tier 1 implements the DSP catalogue schema, catalogue pagination and the catalogue interaction, and none of contract negotiation or transfer, so it makes no DSP conformance claim. Tier 2 and Tier 3 are outlines. Start with the tier model if you want the shape of the ladder before the specifications. </p>

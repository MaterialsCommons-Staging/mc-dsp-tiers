<h1 class="mc-hero__title">Materials Commons DSP Tiers</h1>

<p class="mc-hero__tagline">Tiered profiles of the Dataspace Protocol, DCAT-3 and DCAT-AP for open materials data.</p>

<p class="mc-hero__text"> These are the provider-side entry profiles for the Materials Commons project: minimal, concrete requirements for publishing open, publicly readable datasets and services using the Dataspace Protocol (DSP), DCAT-AP and DCAT-3. Nothing at these levels is access-controlled. DSP Tier 1 still implements the negotiation and transfer flows, because DSP requires them, but they cannot be used to restrict access. </p>

<p class="mc-hero__text"> Tier 0 is a plain DCAT-AP catalogue served over HTTP GET and is not DSP. Tier 1 is the first DSP level. Tier 2 and Tier 3 are outlines. Start with the tier model if you want the shape of the ladder before the specifications. </p>
